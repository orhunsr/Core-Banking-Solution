⚙️ The Core Features

✅ User registration with authentication and authorization (with admin roles)
✅ Email confirmation 
✅ Password reset and verification 
✅ Transaction PIN setup, reset, and verification
✅ Fund transfers, deposits, and withdrawals
✅ Account management (active/inactive)
✅ Real-time email alerts for debit and credit transactions
✅ Admin endpoints for managing customers and accounts
✅ Transaction history
✅ Account freeze/unfreeze (admin)

• .NET Core (C#)
• Entity Framework Core
• PostgreSQL
• ASP.NET Identity
• JWT Authentication
• Clean Architecture
• Repository Pattern & Dependency Injection
• Command Query Responsibility Segregation (CQRS)
• Unit of Work & Database Transactions
• SendGrid SMTP (for email services)
